{% if request.session.language == 'en' %}Method Description{% else %}Descrição do Método{% endif %}

{% if request.session.language == 'en' %} The Copeland & Antikarov approach is a stochastic method for estimating volatility in real options. The value at date 0 (V₀) is the present value of the expected cash flows and stays fixed during the simulation, while the cash flow at period 1 (CF₁) and the present value at date 1 (PV₁) are stochastic. {% else %} A abordagem de Copeland & Antikarov é um método estocástico para estimar a volatilidade em opções reais. O valor presente na data 0 (V₀) é o valor presente dos fluxos de caixa esperados e fica fixo durante a simulação, enquanto o fluxo de caixa no período 1 (FC₁) e o valor presente na data 1 (VP₁) são estocásticos. {% endif %}

{% if request.session.language == 'en' %} Formula: z = ln(V₁/V₀) where V₀ = Σ E[CFₜ]/(1+k)ᵗ and V₁ = CF₁ + PV₁ {% else %} Fórmula: z = ln(V₁/V₀), onde V₀ = Σ E[FCₜ]/(1+k)ᵗ e V₁ = FC₁ + VP₁ {% endif %}

{% if request.session.language == 'en' %} The volatility is calculated as the standard deviation of the z distribution generated from Monte Carlo simulation. {% else %} A volatilidade é calculada como o desvio padrão da distribuição z gerada a partir da simulação de Monte Carlo. {% endif %}
