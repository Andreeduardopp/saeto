{% if request.session.language == 'en' %}Method Description{% else %}Descrição do Método{% endif %}

{% if request.session.language == 'en' %} The Herath & Park approach is a stochastic method for estimating volatility in real options. Unlike the Copeland & Antikarov approach, the value at date 0 (V₀) is stochastic too: it is the present value of a second set of cash flows, drawn independently of the one that gives the cash flow at period 1 (CF₁) and the present value at date 1 (PV₁). {% else %} A abordagem de Herath & Park é um método estocástico para estimar a volatilidade em opções reais. Diferente da abordagem de Copeland & Antikarov, o valor na data 0 (V₀) também é estocástico: é o valor presente de um segundo conjunto de fluxos de caixa, sorteado independentemente do que gera o fluxo de caixa no período 1 (FC₁) e o valor presente na data 1 (VP₁). {% endif %}

{% if request.session.language == 'en' %} Formula: z = ln(V₁/V₀) where V₀ = Σ CF′ₜ/(1+k)ᵗ (independent draw) and V₁ = CF₁ + PV₁ {% else %} Fórmula: z = ln(V₁/V₀), onde V₀ = Σ FC′ₜ/(1+k)ᵗ (sorteio independente) e V₁ = FC₁ + VP₁ {% endif %}

{% if request.session.language == 'en' %} The volatility is calculated as the standard deviation of the z distribution generated from Monte Carlo simulation. {% else %} A volatilidade é calculada como o desvio padrão da distribuição z gerada a partir da simulação de Monte Carlo. {% endif %}
