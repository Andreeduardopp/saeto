{% if language == 'en' %}The Concept{% else %}O Conceito{% endif %}

{% if language == 'en' %} The Prisoner's Dilemma is a standard example of a game analyzed in game theory that shows why two completely rational individuals might not cooperate, even if it appears that it is in their best interests to do so. It was originally framed by Merrill Flood and Melvin Dresher while working at RAND in 1950. {% else %} O Dilema do Prisioneiro é um exemplo padrão de um jogo analisado na teoria dos jogos que mostra por que dois indivíduos completamente racionais podem não cooperar, mesmo que pareça ser do interesse deles fazê-lo. Foi originalmente formulado por Merrill Flood e Melvin Dresher enquanto trabalhavam na RAND em 1950. {% endif %}

{% if language == 'en' %}The Strategies{% else %}As Estratégias{% endif %}
  • {% if language == 'en' %}Always Cooperate (AllC):{% else %}Sempre Cooperar (AllC):{% endif %} {% if language == 'en' %}This strategy consists of always cooperating, regardless of the opponent's previous move.{% else %}Esta estratégia consiste em sempre cooperar, independentemente da jogada anterior do oponente.{% endif %}
  • {% if language == 'en' %}Always Defect (AllD):{% else %}Sempre Trair (AllD):{% endif %} {% if language == 'en' %}This strategy consists of always defecting, regardless of the opponent's previous move.{% else %}Esta estratégia consiste em sempre trair, independentemente da jogada anterior do oponente.{% endif %}
  • {% if language == 'en' %}Tit for Tat (TFT):{% else %}Olho por Olho (OPO):{% endif %} {% if language == 'en' %}This strategy starts by cooperating and then mimics the opponent's previous move. If the opponent cooperates, it cooperates. If the opponent defects, it defects.{% else %}Esta estratégia começa cooperando e depois imita a jogada anterior do oponente. Se o oponente coopera, ele coopera. Se o oponente trai, ele trai.{% endif %}
  • {% if language == 'en' %}Random (Rand):{% else %}Aleatório (Aleat):{% endif %} {% if language == 'en' %}This strategy consists of randomly choosing between cooperating and defecting.{% else %}Esta estratégia consiste em escolher aleatoriamente entre cooperar e trair.{% endif %}
